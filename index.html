🤖 IAs para crear material docente

Guía práctica para profesoras y profesores de Formación Ocupacional (FO): presentaciones, páginas web dinámicas y publicación en GitHub — con la instalación y configuración paso a paso en PowerShell.

1. ¿Qué IA uso para cada tarea?

Resumen rápido según el tipo de material que quieras crear.

Tarea Herramientas recomendadas ¿Se instala en PowerShell?
Presentaciones (diapositivas) Gamma, Canva Magic Design — o bien OpenCode / Kiro / Antigravity para generar diapositivas en HTML Gamma y Canva son web (sin instalar). Los agentes, sí.
Páginas web dinámicas (unidades didácticas, formularios, quiz) OpenCode, Kiro, Antigravity, Claude Code, Gemini CLI — o v0, Bolt, Lovable (web) Sí (agentes)
Subir y publicar en GitHub (GitHub Pages gratis) GitHub CLI (gh) Sí: winget install GitHub.cli
Unificar varios modelos de IA con una sola clave OmniRouter Sí (binario + archivo .env)
Información y novedades de ciberseguridad FreeBuf (portal web, no es una IA) No — es una web: freebuf.com
Idea: los “agentes de código” (OpenCode, Kiro, Antigravity…) no solo programan: con un buen pedido en lenguaje natural crean diapositivas en HTML, webs de unidad didáctica, cuadernos de ejercicios y los suben solos a tu repositorio de GitHub. Son la herramienta más completa para una profesora de FO que quiera material personalizado y siempre actualizable.

① OpenCode Código abierto

En Windows los gestores de paquetes (winget/scoop/choco) no están soportados por su instalador; se instala con npm o con el binario independiente.

Instalación (npm — recomendada)

# 1) Node.js LTS si aún no lo tienes
winget install OpenJS.NodeJS.LTS

# 2) Reinicia PowerShell y instala OpenCode
npm install -g @opencode/cli

# 3) Comprobar
opencode --version

Instalación alternativa (binario sin dependencias)

$zip = "$env:TEMP\opencode.zip"
Invoke-WebRequest -Uri "https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip" -OutFile $zip
Expand-Archive $zip -DestinationPath "$env:LOCALAPPDATA\opencode" -Force
# Añadir esa carpeta a la variable PATH del sistema para usar "opencode" desde cualquier carpeta

Configuración y primer uso

# Ir a la carpeta de tu material (o crear una nueva)
mkdir C:\mis-clases\fo-web
cd C:\mis-clases\fo-web

# Arrancar OpenCode
opencode
  • Dentro del programa escribe /connect y elige tu proveedor (Anthropic, OpenAI, Google, Amazon…); también puedes ejecutar opencode auth login desde la terminal.
  • Configuración global en ~/.config/opencode/opencode.json; por proyecto, opencode.json en la carpeta.
  • Ejemplo de uso docente: “Crea una presentación HTML de 10 diapositivas sobre prevención de riesgos laborales y guárdala en presentacion/index.html”.

Docs: opencode.ai/docs

② Kiro (AWS) CLI + IDE + Web

Requisitos oficiales del CLI: Windows 11 con Windows Terminal o PowerShell (no Símbolo del sistema). En Windows 10, instala la IDE con winget.

Instalación del CLI (PowerShell)

# Instalador oficial de Kiro CLI (descarga y verifica el MSI automáticamente)
irm 'https://cli.kiro.dev/install.ps1' | iex

# Abrir una ventana NUEVA de PowerShell y comprobar
kiro-cli --version

Instalación de la IDE (alternativa / Windows 10)

winget install Amazon.Kiro        # IDE de escritorio
winget install Amazon.KiroCrew     # agente personal persistente (opcional)

Configuración y primer uso

cd C:\mis-clases\fo-web
kiro-cli login     # inicio de sesión en el navegador
kiro-cli chat      # abre la sesión de chat en la terminal
  • Primer arranque: te preguntan esquema de color, modo de render y workspace trust (confirma que confías en la carpeta).
  • Dentro del chat: /guide (ayuda), /model (cambiar modelo), Shift+Tab (modo plan antes de actuar).
  • Para que entienda tu materia: crea .kiro\steering\proyecto.md con el contexto de tus unidades didácticas.

Docs: kiro.dev/docs

③ Antigravity (Google) Gratis

Incluye la Antigravity App (escritorio), el Antigravity IDE y la Antigravity CLI (agy).

Instalación de la CLI (PowerShell)

# Instalador oficial de Google (PowerShell)
irm https://antigravity.google/cli/install.ps1 | iex

# Comprobar (abre una terminal nueva si hace falta)
agy --version

Instalación de la app de escritorio (opcional)

# Windows 10/11 x64 — descarga el instalador oficial
Invoke-WebRequest -Uri "https://storage.googleapis.com/antigravity-public/antigravity-hub/2.35.1-4615540875067392/windows-x64/Antigravity-x64.exe" -OutFile "$env:USERPROFILE\Downloads\Antigravity-x64.exe"
explorer "$env:USERPROFILE\Downloads\Antigravity-x64.exe"   # ejecuta el instalador y sigue el asistente

Configuración y primer uso

mkdir C:\mis-clases\fo-web
cd C:\mis-clases\fo-web
agy          # primer arranque: colores, modo de render y confianza en la carpeta
agy -i "Crea una web de la unidad de cocina con un quiz de 5 preguntas"
  • Inicia sesión con tu cuenta personal de Google (o cuenta Gemini Enterprise/Cloud si tu centro la facilita).
  • Atajos útiles: Ctrl+R revisar cambios, Shift+Tab cambiar modo (auto/plan), /exit salir.
  • También existe como extensión de VS Code, Visual Studio, JetBrains, Zed, Xcode y Eclipse.

Docs: antigravity.google/docs

3. OmniRouter — un solo enlace para varios modelos

Router local (código abierto, MIT) que unifica varios modelos de IA detrás de una sola clave compatible con OpenAI y Anthropic, con panel web de control.

¿Para qué sirve a una profesora? En vez de gestionar claves de Qwen, GLM, DeepSeek, Gemini… por separado, arrancas OmniRouter una vez y cualquier herramienta (OpenCode, Claude Code, etc.) habla con él usando http://localhost:8080/v1 y una clave sk-…. Si un modelo falla, salta automáticamente al siguiente (failover).

Instalación en PowerShell (Windows)

  1. Descargar y descomprimir la última versión 
    $zip = "$env:TEMP\omnirouter.zip"
Invoke-WebRequest -Uri "https://github.com/Godde3s/omnirouter/releases/download/v1.4.0/dist-omnirouter-windows-amd64.zip" -OutFile $zip
Expand-Archive $zip -DestinationPath "$env:USERPROFILE\omnirouter" -Force
cd "$env:USERPROFILE\omnirouter"
    Contenido: omnirouter-windows-amd64.exe, .env.example, start.bat, y los ayudantes ds-login-windows-amd64.exe y qwen-bx-windows-amd64.exe.
  2. Crear la configuración 
    Copy-Item .env.example .env
notepad .env
    Variables mínimas que conviene revisar: 
    PORT=8080                     # puerto del panel
ADMIN_PASSWORD=               # vacío = genera una clave aleatoria (se imprime en el log)
DEEPSEEK_TOKENS=              # opcional - se obtiene con .\ds-login-windows-amd64.exe
QWEN_TOKENS=                  # opcional (también funciona como invitado)
GEMINI_COOKIES=               # opcional (también funciona como invitado)
AUTO_CHAIN=qwen/qwen3.8-max,ds/deepseek-chat,gemini/gemini-3.6-flash
AGENT_MODE=1                  # activa tool-calling para los agentes
  3. Arrancar 
    .\omnirouter-windows-amd64.exe      # o bien: .\start.bat
    Abre el panel en http://localhost:8080.
  4. Conectar tus herramientas (por ejemplo OpenCode u otro agente): 
    Base URL:  http://localhost:8080/v1
API Key:   sk-…        (la crea el panel en "Claves")
Model:     auto        (elige el mejor proveedor disponible con failover)
    Para clientes compatibles con Anthropic (tipo Claude Code): ANTHROPIC_BASE_URL=http://localhost:8080 y ANTHROPIC_API_KEY=sk-….
Aviso: OmniRouter está en desarrollo activo y está pensado para uso personal/educativo. Revisa las condiciones de uso de cada servicio al que te conectes y no subas a Internet el panel con ADMIN_PASSWORD vacío.

Proyecto: github.com/Godde3s/omnirouter · Demo: godde3s.github.io/omnirouter

4. GitHub: tu repositorio y tu página web gratis

GitHub es donde guardas (y publicas) todo el material generado. Se controla desde PowerShell con GitHub CLI (gh).

Instalación

winget install GitHub.cli

# Cerrar y abrir PowerShell, luego identificarte (abre el navegador)
gh auth login

Crear un repositorio y subir tu material

# Ir a la carpeta de tu proyecto
cd C:\mis-clases\fo-web

# Preparar Git (solo la primera vez en ese PC)
git init
git add .
git commit -m "Material de clase"

# Crear el repositorio en GitHub y subirlo (público)
gh repo create ias-material-fo --public --source . --push

Publicar como página web (GitHub Pages)

# Activar GitHub Pages desde la rama principal
gh api -X POST repos/{owner}/ias-material-fo/pages -f "source[branch]=main" -f "source[path]=/"

# Ver la URL resultante
gh api repos/{owner}/ias-material-fo/pages --jq .html_url
Resultado: tu material queda en https://<usuario>.github.io/ias-material-fo/ — enlaces para tus alumnos que no caducan y se actualizan con cada git push.

Actualizaciones diarias

cd C:\mis-clases\fo-web
git add .
git commit -m "Actualiza la unidad 3"
git push

5. Presentaciones y páginas web sin instalar nada

Alternativas 100 % web, útiles cuando no quieres tocar PowerShell.

Gamma Web

Genera presentaciones completas a partir de un tema o de un texto. Exporta a PDF/PPTX. Ideal para clases magistrales rápidas.

gamma.app

Canva Magic Design Web

Diseño de diapositivas, infografías y hojas de trabajo con plantillas. Muy visual y con colaboración para equipos docentes.

canva.com

v0 · Bolt · Lovable Web

Generadores de páginas web dinámicas describiendo lo que quieres. Buen complemento a los agentes cuando solo necesitas una web sencilla.

v0.app · bolt.new · lovable.dev

Consejo: si el material debe durar y ser editable, prioriza los agentes (sección 2) + GitHub (sección 4). Si solo necesitas algo para mañana por la mañana, usa Gamma o Canva.

6. FreeBuf (aclaración)

FreeBuf no es una herramienta de IA para crear material. Es un portal web de noticias y artículos de ciberseguridad (freebuf.com), muy reconocido en el ámbito hispanohablante y anglosajón. No se instala ni se configura en PowerShell: se consulta desde el navegador. Útil para estar al día en ciberseguridad si tus unidades de FO incluyen contenidos de seguridad informática o RGPD; no sirve para generar presentaciones ni webs.

7. Flujo de trabajo completo (ejemplo real)

De la idea a la web pública en cinco pasos, todo desde PowerShell.

  1. Crear la carpeta del proyecto 
    mkdir C:\mis-clases\fo-web
cd C:\mis-clases\fo-web
git init
  2. Arrancar el agente (OpenCode, Kiro o Antigravity) y pedirle el material: 
    opencode        # o: kiro-cli   /   agy
    Ejemplo de pedido: “Crea una web estática de la unidad ‘Mecanizado básico’: índice, teoría resumida, 8 preguntas de autoevaluación con corrección y una tabla de herramientas. En español.”
  3. Revisar el resultado en el navegador (el agente te dice la ruta, p. ej. index.html).
  4. Subirlo a GitHub 
    git add .
git commit -m "Unidad mecanizado - material"
gh repo create fo-mecanizado --public --source . --push
  5. Publicar y compartir la URL de GitHub Pages con tus alumnos (ver sección 4).

8. Problemas frecuentes en PowerShell

SíntomaCausaSolución
… no se reconoce como cmdlet Programa recién instalado Cierra y vuelve a abrir PowerShell; si sigue, reinicia el PC (PATH).
winget no se reconoce Windows 10 muy antiguo o App Installer ausente Instala “Instalador de aplicaciones” desde Microsoft Store, o usa el instalador oficial de cada herramienta.
Ejecución de scripts deshabilitada Política de ejecución de PowerShell Set-ExecutionPolicy -Scope CurrentUser RemoteSigned (los irm … | iex no se ven afectados).
kiro-cli no existe CLI de Kiro requiere Windows 11 Usa la IDE: winget install Amazon.Kiro.
npm/node no existen Node.js no instalado winget install OpenJS.NodeJS.LTS y abre una terminal nueva.
El agente no “ve” Internet o fallan las claves Proveedor de IA sin credenciales Conéctalo con /connect (OpenCode), kiro-cli login o tu clave API en variables de entorno.
OmniRouter no abre el panel Puerto ocupado o proceso cerrado Cambia PORT en .env, reinicia el .exe y abre http://localhost:8080.
Seguridad y protección de datos: no subas nunca a GitHub datos personales de alumnado (nombres, notas, DNI, fotos). Usa repos privados para material con datos y revisa siempre el contenido generado por IA antes de compartirlo en clase.
